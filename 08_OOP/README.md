# 08_OOP

Object-Oriented Programming: modeling the world as interacting objects.
One running example (bank accounts, animals) grows across all five lessons.

| # | Topic | What you'll learn |
|---|-------|-------------------|
| 1 | [Classes](01_Classes/notes.ipynb) | class keyword, __init__, self demystified, __str__/__repr__ |
| 2 | [Objects](02_Objects/notes.ipynb) | Instantiation, instance state, identity, isinstance, dynamic attributes |
| 3 | [Inheritance](03_Inheritance/notes.ipynb) | Parent/child classes, super(), overriding, MRO basics, composition vs inheritance |
| 4 | [Polymorphism](04_Polymorphism/notes.ipynb) | One interface many behaviors, duck typing, operator overloading teaser |
| 5 | [Encapsulation](05_Encapsulation/notes.ipynb) | Protected/private conventions, name mangling, @property getters/setters |

Each folder contains `exercises.ipynb` (practice) and `solutions.ipynb` (check after trying).
