# 04_Data_Structures

Python's four built-in containers — how each stores data, what it's fast at,
and which to reach for. Ends with a one-stop cheat sheet for revision.

| # | Topic | What you'll learn |
|---|-------|-------------------|
| 1 | [Lists](01_Lists/notes.ipynb) | Indexing/slicing, add/remove/sort methods, copies vs references |
| 2 | [Tuples](02_Tuples/notes.ipynb) | Immutability, packing/unpacking, single-element gotcha, tuples as dict keys |
| 3 | [Sets](03_Sets/notes.ipynb) | Uniqueness, set algebra (union/intersection/difference), O(1) membership |
| 4 | [Dictionaries](04_Dictionaries/notes.ipynb) | Key-value storage, get()/items()/update(), nested dicts, dict comprehension |
| 5 | [List Comprehension](05_List_Comprehension/notes.ipynb) | Compact transforms & filters, dict/set comprehensions, readability rules |
| 📌 | [Cheat Sheet](Python%20Data%20Structures%20Cheat%20Sheet.ipynb) | Side-by-side comparison tables + method quick reference for all four |

Each folder contains `exercises.ipynb` (practice) and `solutions.ipynb` (check after trying).
