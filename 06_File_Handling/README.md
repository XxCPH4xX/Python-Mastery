# 06_File_Handling

Programs become useful when they remember things: reading, writing, appending,
and processing structured CSV data.

| # | Topic | What you'll learn |
|---|-------|-------------------|
| 1 | [Read Files](01_Read_File/notes.ipynb) | open() modes, read/readline/readlines, the with-statement, encodings |
| 2 | [Write Files](02_Write_File/notes.ipynb) | Writing & overwriting safely, write/writelines, newlines |
| 3 | [Append Files](03_Append_File/notes.ipynb) | Appending logs, "a+" mode, exclusive creation with "x", file cursor |
| 4 | [CSV](04_CSV/notes.ipynb) | csv reader/writer, DictReader/DictWriter, computing stats on datasets |

Each folder contains `exercises.ipynb` (practice) and `solutions.ipynb` (check after trying).
