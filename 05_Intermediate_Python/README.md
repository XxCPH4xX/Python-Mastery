# 05_Intermediate_Python

The standard library and tooling that separate beginners from productive
developers: modules, math utilities, dates, JSON, regex, and package management.

| # | Topic | What you'll learn |
|---|-------|-------------------|
| 1 | [Modules](01_Modules/notes.ipynb) | import styles, creating your own modules, __name__ == "__main__" |
| 2 | [Math](02_Math/notes.ipynb) | Built-in math helpers, math module, rounding traps, decimal for money |
| 3 | [Datetime](03_Datetime/notes.ipynb) | Dates & times, strftime/strptime, timedelta arithmetic, timezones |
| 4 | [JSON](04_JSON/notes.ipynb) | dumps/loads, files, type mapping table, pretty-printing, API-shaped data |
| 5 | [Regex](05_Regex/notes.ipynb) | Patterns, metacharacters, findall/search/sub, practical mini-patterns |
| 6 | [PIP](06_PIP/notes.ipynb) | Installing packages, requirements.txt, version pinning |
| 7 | [Virtualenv](07_Virtualenv/notes.ipynb) | Isolated environments per project, activation on every OS, best workflow |

Each folder contains `exercises.ipynb` (practice) and `solutions.ipynb` (check after trying).
