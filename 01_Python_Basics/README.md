# 01_Python_Basics

The foundation of everything: storing data, working with text and numbers, making
decisions, and talking to the user. Master this module before anything else.

| # | Topic | What you'll learn |
|---|-------|-------------------|
| 1 | [Variables](01_Variables/Python%20Variables.ipynb) | Creating variables, dynamic typing, naming rules, how Python stores values |
| 2 | [Data Types](02_Data_Types/Python%20Data_types.ipynb) | str, int, float, bool, list — `type()`, and choosing the right type |
| 3 | [Numbers](03_Numbers/Python%20Numbers.ipynb) | int / float / complex, numeric operations, random numbers |
| 4 | [Casting](04_Casting/Python%20Casting.ipynb) | Converting between types with int(), float(), str() |
| 5 | [Strings](05_Strings/Python%20Strings/) | String basics, slicing, and modification methods |
| 6 | [Booleans](06_Booleans/notes.ipynb) | True/False, truthy & falsy values, comparisons |
| 7 | [Operators](07_Operators/notes.ipynb) | Arithmetic, assignment, comparison, logical, identity, membership, bitwise |
| 8 | [User Input](08_User_Input/notes.ipynb) | input(), converting types, validating what the user types |

Each folder contains `exercises.ipynb` (practice) and `solutions.ipynb` (check after trying).
