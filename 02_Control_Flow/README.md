# 02_Control_Flow

Teaching your program to make decisions and repeat work: the if/else family,
the modern match statement, and every flavor of loop.

| # | Topic | What you'll learn |
|---|-------|-------------------|
| 1 | [If...Else](01_If_Else/notes.ipynb) | if / elif / else, nesting, ternary expressions, truthiness in conditions |
| 2 | [Match](02_Match/notes.ipynb) | Structural pattern matching (Python 3.10+): literals, guards, sequences |
| 3 | [While Loops](03_While_Loop/notes.ipynb) | Condition-controlled repetition, counters, accumulators, infinite-loop safety |
| 4 | [For Loops](04_For_Loop/notes.ipynb) | Iterating sequences, range(), enumerate(), zip(), nested loops |
| 5 | [Break & Continue](05_Break_Continue/notes.ipynb) | Exiting early, skipping iterations, pass, and loop-else |

Each folder contains `exercises.ipynb` (practice) and `solutions.ipynb` (check after trying).
