# 03_Functions

Writing reusable, readable code: from your first `def` to flexible argument
handling, clean return patterns, scope rules, and lambda one-liners.

| # | Topic | What you'll learn |
|---|-------|-------------------|
| 1 | [Functions](01_Functions/notes.ipynb) | def, calling, parameters vs arguments, docstrings, functions as objects |
| 2 | [Arguments](02_Arguments/notes.ipynb) | Positional/keyword args, defaults, *args/**kwargs, the mutable-default trap |
| 3 | [Return Values](03_Return_Values/notes.ipynb) | Returning single/multiple values, early returns, print-vs-return |
| 4 | [Scope](04_Scope/notes.ipynb) | Local vs global, LEGB rule, global/nonlocal keywords, closures teaser |
| 5 | [Lambda](05_Lambda/notes.ipynb) | Anonymous functions, sorted/map/filter, when NOT to use lambda |

Each folder contains `exercises.ipynb` (practice) and `solutions.ipynb` (check after trying).
